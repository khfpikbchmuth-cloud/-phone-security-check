🔐 بررسی امنیت تلفن

ابزاری برای بررسی و ارزیابی امنیت گوشی‌های اندرویدی با استفاده از Termux و Python.

امکانات پروژه

- بررسی وضعیت شبکه
- بررسی تنظیمات DNS
- بررسی اتصال اینترنت
- نمایش اطلاعات دستگاه
- بررسی تنظیمات امنیتی اندروید
- شناسایی تنظیمات مشکوک
- بررسی وضعیت دسترسی‌ها
- تهیه گزارش امنیتی
- نمایش نتایج بررسی به زبان ساده

محیط اجرا

- Android
- Termux
- Python 3

نصب پیش‌نیازها

ابتدا Termux را باز کنید و دستورات زیر را اجرا کنید:

pkg update && pkg upgrade -y
pkg install python -y
pkg install git -y

بررسی نصب Python:

python --version

هدف پروژه

هدف این پروژه کمک به کاربران برای بررسی وضعیت امنیت گوشی‌های اندرویدی و شناسایی مشکلات احتمالی امنیتی است.

حریم خصوصی و امنیت

- عدم جمع‌آوری مخفیانه اطلاعات
- عدم دسترسی غیرمجاز به دستگاه‌های دیگر
- عدم ارسال اطلاعات شخصی به سرور خارجی
- اجرای بررسی‌ها با اجازه صاحب دستگاه
